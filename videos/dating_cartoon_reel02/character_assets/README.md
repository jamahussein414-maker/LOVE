# Reusable 2D cast: The Overthinker + The Friend

Rigged SVG characters for Remotion (src/characters.tsx). Each character is one component driven by a `Pose`:
brows (raise + angle), eye open/scale/look, mouth (open + smile/smirk), head tilt/turn, body lean,
phone height (Overthinker), glasses slide (Friend), blush. Lip-sync comes from `talk(t, who)`, which reads
a 60 fps loudness envelope generated by tts.py; blinking from `blinkAt`.

- src/characters.tsx: Overthinker, Friend (reusable in any episode)
- src/lib.ts: Pose type, keyframed poseAt(), talk() lip-sync, blinkAt()
- src/scenes.tsx: Reel 02 shots, café sets (SetA/SetB/Table), captions, phone rewrite, end card, Sheets
- reference/: cast sheet + expression sheets

Voices: Kokoro TTS. Overthinker = am_eric, Friend = am_michael.
Rebuild: npm i remotion@4.0.544 @remotion/cli @remotion/renderer @remotion/bundler react@18.3.1 react-dom@18.3.1;
add Inter fonts + Noto emoji PNGs to public/; python3 tts.py <kokoro_dir>; python3 timeline.py;
node render.mjs sheets|video; python3 audio.py; mux with ffmpeg.
